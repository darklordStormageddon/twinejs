# 두 번째 오늘 — 인터랙티브 픽션

단편 「두 번째 오늘 — 형준과 정희의 이야기」를 이 리포지토리의 Twine 스토리 포맷
(**Harlowe 3.3.9**, `public/story-formats/harlowe-3.3.9`)으로 옮긴 플레이 가능한 게임입니다.

## 파일

| 파일 | 설명 |
| --- | --- |
| `second-today.html` | 빌드된 게임. 브라우저로 바로 열어 플레이할 수 있습니다. |
| `second-today.twee` | 원본 소스(Twee 3). 34개 패시지, 스타일시트 포함. |
| `build.mjs` | Twee → HTML 빌드 스크립트. Twine의 `publishStoryWithFormat`(`src/util/publish.ts`)과 같은 형식으로 출력합니다. |

## 플레이

`second-today.html`을 브라우저에서 열면 됩니다.

## Twine에서 편집

두 가지 방법 중 하나를 쓰면 됩니다.

- Twine 실행 → **라이브러리 → 가져오기(Import)** → `second-today.html` 선택
- Twine 실행 → **라이브러리 → 가져오기(Import)** → `second-today.twee` 선택 (Twee 가져오기 지원)

## 다시 빌드

`.twee`를 고친 뒤 리포지토리 루트에서 실행합니다(추가 패키지 불필요, Node 20+).

```bash
node stories/second-today/build.mjs
```

스크립트는 깨진 링크(`[[...]]`, `(go-to:)`)가 있으면 빌드를 멈춥니다.

## 구성

- **1장 「예약된 자리」 — 형준 시점**: 메시지, 커피 주문, 통화 중 말 고르기 등 11개의 선택.
- **2장 「하지 않아도 되는 말」 — 정희 시점**: 같은 하루를 정희로 다시 보냅니다.
  형준이 보낸 메시지(하트, 농담, 사진, 라테/아메리카노)와 통화에서 한 말이
  정희 쪽 장면에 그대로 도착하고, 정희의 반응도 달라집니다.
- **결말 3개**
  - `삼키기 쉬운 국` — 정희가 〈좋았던 순간도 진심이었어.〉를 지운다 (원작 결말)
  - `보낸 문장` — 메시지를 보내고, 형준이 끝까지 붙잡았던 경우
  - `나도` — 메시지를 보내고, 형준이 놓아주었던 경우

원작의 주제에 맞게, 어떤 선택을 해도 정희는 카페에 오지 않습니다.
선택이 바꾸는 것은 결과가 아니라 그 하루를 지나는 방식입니다.
각 장면에서 원작과 같은 선택은 항상 첫 번째 선택지입니다.
